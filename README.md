One line of horror for make.fun's "One Line, One Chill" bounty: a single sentence under 200 characters that has to frighten a reader in one breath. The program writes the line to `/output/entry.txt` — a mundane nightly routine broken by one impossible detail, the threat already in the room, no explanation offered.

## Run it

```sh
python3 main.py
```
